# Birthday Surprise — GitHub Pages

A five-page romantic birthday website using HTML, CSS and JavaScript.

## 1. Personalize it
Open `script.js` and replace:
```js
const GIRLFRIEND_NAME = "my love";
```
with the name you want to display.

## 2. Add your media
Create an `assets` folder and add:
- `cover.jpg` — cover photo
- `photo1.jpg`, `photo2.jpg`, `photo3.jpg` — memory photos
- `birthday.mp3` — background music
- `memories.mp4` — memory video

The site still opens if you haven't added the optional images yet. Media filenames must match exactly, including capitalization.

## 3. Upload to GitHub
1. Sign in at https://github.com and create a new repository, for example `birthday-surprise`.
2. Upload `index.html`, `letter.html`, `memories.html`, `interlude.html`, `final.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
5. Wait for publishing. Your site URL will look like `https://YOUR-USERNAME.github.io/birthday-surprise/`.

## Notes
- Background music needs a button click because browsers often block autoplay.
- Test the site before sharing it.
- GitHub Pages sites are public by default. Avoid uploading private or sensitive photos/videos.
